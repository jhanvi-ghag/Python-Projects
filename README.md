# Password Strength Checker

## Project Description
This is a Python project that checks whether a password is strong or weak based on basic security conditions.

## Objective
To help users understand the importance of creating strong and secure passwords.

## Technology Used
- Python 3.14
- Regular Expressions

## Features
1. Checks password length (minimum 8 characters).
2. Checks uppercase letters.
3. Checks lowercase letters.
4. Checks numbers.
5. Checks special characters (@, #, $).

## Sample Output

**Input:** Jhanvi@123

**Output:** Strong Password

## How to Run
1. Install Python.
2. Download the Python file.
3. Open it in Python IDLE.
4. Press F5 to execute the program.
5. Enter a password.
